# 440 Hermes Team Roles

These role profiles are source-tracked in Git and copied to `/opt/data/roles/` on Hermes boot.

The Slack Concierge is the parent communicator. The other roles are delegated work identities used to scope subagent work and decide what tools, artifacts, verification, and escalation path apply.

The LLM wiki is the source-tracked corporate memory workspace at `/workspace/llm-wiki` (`440ai/llm-wiki`). Use it for durable, source-backed memory that agents should reuse. Keep active task/project tracking in GitHub issues.

Roles:

- `slack-concierge.md`
- `chief-of-staff.md`
- `product-manager.md`
- `gtm.md`
- `engineering.md`
- `security.md`
- `agent-ops.md`

Task/project notes, reviews, follow-ups, and blocker reports belong in GitHub issues. Repo docs are reserved for stable architecture, runbooks, and static reference material.
